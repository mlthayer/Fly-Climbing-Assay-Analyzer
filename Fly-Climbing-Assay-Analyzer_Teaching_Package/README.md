# Fly Climbing Assay Analyzer

Browser-based software and undergraduate laboratory module for standardized scoring of *Drosophila melanogaster* negative geotaxis assays.

## Launch the app
Open `index.html` locally or use GitHub Pages after publishing the repository.

## Teaching materials included
- `docs/Fly_Climbing_Assay_Analyzer_Complete_Lab_Module.pdf` - complete student and instructor module
- `docs/Fly_Climbing_Assay_Analyzer_Complete_Lab_Module.docx` - editable version
- `examples/example_fly_assay_results.csv` - example exported data
- `analysis/fly_assay_analysis_template.R` - R analysis starter script

## Suggested course use
This platform can support undergraduate genetics, physiology, neuroscience, aging biology, toxicology, research methods, or CURE-style laboratory courses. Students can use the software to move from video-based observation to quantitative data collection, CSV export, statistical analysis, visualization, and biological interpretation.

## GitHub Pages
After uploading this repository to GitHub, go to Settings -> Pages -> Deploy from branch -> main -> root. The app will open from your GitHub Pages URL.
