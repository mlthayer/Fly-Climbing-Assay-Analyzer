# Fly Climbing Assay Analyzer
[![DOI](https://zenodo.org/badge/1295392899.svg)](https://doi.org/10.5281/zenodo.21281685)

**Fly Climbing Assay Analyzer** is a browser-based tool for standardized manual scoring of *Drosophila melanogaster* negative geotaxis assays.

The software was designed for videos containing six vials and five repeated climbing trials. It allows users to upload assay videos, correct video orientation, calibrate individual vial boundaries, mark the 5-cm climbing threshold, enter fly counts, automatically calculate percent climbed, and export analysis-ready CSV files.

## Features

- Browser-based; no installation required
- Runs locally in Chrome, Edge, Safari, or Firefox
- Multi-video support
- Independent scoring windows for each video
- Rotate and flip videos without modifying original files
- Enlarged viewer with persistent orientation
- Individual vial box calibration
- 5-cm threshold calibration
- Trial-specific scoring for five trials
- Total flies per vial entry
- Automatic percent climbed calculation
- Metadata fields for genotype, sex, treatment, and replicate
- Export individual or combined CSV files
- Save and reload scoring sessions

## Quick Start

1. Open `index.html` in a modern web browser.
2. Upload one or more assay videos.
3. Correct the video orientation if needed.
4. Set the 5-cm climbing threshold.
5. Set individual vial boxes by clicking the left and right side of each vial.
6. Enter the total number of flies per vial.
7. Record the number of flies reaching at least 5 cm for each vial and trial.
8. Export the results as CSV.

## Recommended Browser

Google Chrome or Microsoft Edge are recommended.

## Data Privacy

All video processing and scoring occur locally in the browser. Videos are not uploaded to a server.
