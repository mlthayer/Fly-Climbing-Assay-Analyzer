# User Guide

## Purpose

The Fly Climbing Assay Analyzer standardizes manual scoring of Drosophila negative geotaxis videos.

## Workflow

1. Upload videos.
2. Correct orientation.
3. Set the 5-cm threshold line.
4. Set each vial box.
5. Enter total flies per vial.
6. Score flies at or above 5 cm for each trial.
7. Export CSV.

## Vial Box Calibration

Click the left and right side of each vial. Repeat for Vials 1 through 6.

## CSV Output

The exported CSV contains:
- video file
- genotype
- sex
- treatment
- replicate
- trial
- vial
- count above 5 cm
- total flies
- percent climbed
- orientation settings
- calibration settings
