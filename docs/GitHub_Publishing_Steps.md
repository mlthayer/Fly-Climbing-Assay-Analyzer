# GitHub Publishing Steps

## 1. Create a GitHub repository

Recommended repository name:

`Fly-Climbing-Assay-Analyzer`

Description:

`Browser-based software for standardized scoring of Drosophila negative geotaxis assays.`

## 2. Upload files

Upload:
- `index.html`
- `README.md`
- `LICENSE`
- `CITATION.cff`
- `CHANGELOG.md`
- `CONTRIBUTING.md`
- `docs/User_Guide.md`

## 3. Enable GitHub Pages

Settings → Pages → Deploy from branch → main → root

After deployment, the app will be accessible at:

`https://YOUR-USERNAME.github.io/Fly-Climbing-Assay-Analyzer/`

## 4. Create a release

Create release `v1.0.0`.

## 5. Archive with Zenodo

Connect GitHub to Zenodo and archive the release to obtain a DOI.
